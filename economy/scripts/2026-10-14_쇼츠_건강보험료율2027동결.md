# [타겟/주제]
- 타겟: 25~45세 직장인(경제 초보), 매달 월급에서 건강보험료가 빠지는 모든 근로소득자
- 주제: 2027년 건강보험료율 7.19% 동결(올해와 동일) — "요율은 안 올랐지만 내 공제액은 늘 수 있는 이유"

---

## 훅 (0~3초)
"월급에서 빠지는 건강보험료, 내년엔 얼마나 될까요?" 🤔
(자막: **"2027년 건강보험료율 7.19%, 동결"**)

## 본문 (40~55초, 120~160자 내레이션 기준)

1. **뉴스 한 줄**
   보건복지부가 9월 8일 건강보험정책심의위원회에서 2027년도 건강보험료율을 올해와 같은 7.19%로 동결했습니다. 직장가입자는 보수월액의 7.19%를 회사와 절반씩 나눠 내는데, 내가 직접 부담하는 몫은 3.595%로 그대로입니다.

2. **내 돈 영향**
   요율 자체는 안 올랐지만, 내 연봉이나 월급이 오르면 보험료 공제액은 자동으로 같이 늘어나요. "요율 동결"이 "내 공제액도 그대로"라는 뜻은 아니라는 점이 포인트예요.
   [내 의견] (여기에 "월급 올랐는데 공제액도 늘어서 체감이 달랐다" 같은 직접 겪은 반응이나 코멘트를 1~2문장 채워 넣으세요 — 정책 위험 방지용으로 비워둡니다.)

3. **지금 할 일 1개**
   국민건강보험공단 홈페이지의 4대보험 모의계산기로 내 월급 기준 실제 공제액을 한 번 확인해보세요. 연봉이 오른 분이라면 내년 실수령액 계산에도 미리 반영해두면 좋아요.

4. **CTA**
   "이번 주 경제 뉴스, 일요일 주간정리에서 다른 소식들과 함께 더 정리해드릴게요 — 구독하고 기다려주세요."

## 첫 화면/썸네일 문구 & 비주얼 연출
- **문구**: "건강보험료율, 내년도 동결" (큰 글씨) + 작은 글씨 "7.19%, 그대로"
- **연출**: 네이비 배경 + 평행선(동결을 뜻하는 수평 그래프 아이콘) + 월급봉투/급여명세서 아이콘(AI 일러스트, 실제 공단 로고·방송사 화면 금지)
- **씬 구성 아이디어**:
  1. "7.19%" 숫자 등장 + 평행선 그래프 애니메이션 (훅)
  2. "동결" 도장 느낌 텍스트 효과
  3. 급여명세서 아이콘 + "내 월급 오르면 공제액도 같이" 비교 그래픽
  4. 계산기 아이콘 체크리스트 등장
  5. 구독 유도 CTA 화면

## 쇼츠↔롱폼 연결 방법
- 쇼츠 하단 고정 댓글: "이번 주 경제 뉴스 전체 정리는 일요일 롱폼에서 (링크)"
- 쇼츠 종료 화면에 관련 동영상으로 추후 업로드할 일요일 롱폼 연결 (현재는 플레이스홀더, 롱폼 업로드 후 실제 링크로 교체)

## 제목 후보 (3~5개)

1. **"건강보험료율, 내년에도 똑같다는데..."**
   — 클릭 이유: "그런데?"라는 궁금증을 유발하는 말줄임 구조
2. **"요율은 동결, 그런데 왜 내 공제액은 늘어날까"**
   — 클릭 이유: 모순처럼 들리는 문장으로 클릭 유도
3. **"2027년 건강보험료, 직장인이 알아야 할 숫자 하나"**
   — 클릭 이유: 타깃을 명확히 호명하고 "숫자 하나"로 간결함 강조
4. **"월급 오른 분들, 이거 꼭 확인하세요"**
   — 클릭 이유: 행동 유도형 문구로 해당자의 클릭률 높임
