# 아동용 유튜브 채널 (신규, 2026-10-15~)

이 폴더는 **아빠모해TV와는 완전히 다른, 별도의 유튜브 채널**을 위한 콘텐츠다.
루트 `CLAUDE.md`/`youtube-guide.md`의 트랙 A/B 규칙(뉴스 쇼츠, 경제 해설)은
이 폴더에는 적용되지 않는다 — 아동용 캐릭터 애니메이션 채널이라 소재·톤·제작
방식이 전혀 다르기 때문에 규칙을 분리해서 관리한다.

- **채널명**: [확인 필요 — 사용자가 알려줄 것]
- **타겟**: 한국어, 미취학 아동(3~6세)
- **콘텐츠 형태**: 오리지널 캐릭터가 등장하는 짧은 스토리 애니메이션

## 제작 파이프라인

1. **캐릭터 설계** (`characters/`): Higgsfield의 character-sheet 워크플로로
   일관된 캐릭터 시트(여러 각도/표정)를 먼저 만든다. 한 번 정해진 캐릭터의
   생김새·색·의상은 이후 에피소드에서 그대로 유지한다(일관성이 곧
   브랜드다).
2. **스토리 작성** (`scripts/`): 미취학 아동 기준으로 짧고(2~4분), 반복적인
   구조, 쉬운 단어, 하나의 명확한 교훈(나눔·배려·정리 등)을 담는다. 공포·
   폭력·자극적 소재는 쓰지 않는다.
3. **영상 제작**: Higgsfield의 캐릭터 애니메이션 도구로 스토리의 각 장면을
   캐릭터가 등장하는 영상으로 만든다(실제 캐릭터가 움직이는 애니메이션 —
   트랙 A처럼 스톡 영상 위에 자막만 얹는 방식이 아님).
4. **내레이션/음성**: 아이 친화적인 한국어 음성으로 더빙(구체적 음성 선택은
   첫 에피소드 제작 시 사용자와 함께 확정).
5. **합주/편집**: 장면 영상 + 음성 + 자막을 합쳐 완성한다.

## 알아둘 것

- **Higgsfield 계정 크레딧이 매우 부족한 상태(2026-10-15 기준 3.56
  크레딧, free 플랜)다.** 캐릭터 시트 1장, 영상 장면 생성 등 실제 생성
  작업에는 크레딧(또는 플랜 업그레이드/크레딧 충전)이 필요하다 — 생성을
  실행하기 전에 항상 사용자에게 먼저 확인한다.
- 캐릭터는 실존 인물·유명 캐릭터(저작권)를 모사하지 않는다 — 항상
  오리지널 디자인.
- 아동용 콘텐츠이므로 폭력·공포·연애·과도한 자극 요소를 넣지 않는다 —
  YouTube 아동용 콘텐츠 정책(COPPA 등)도 함께 고려한다.
