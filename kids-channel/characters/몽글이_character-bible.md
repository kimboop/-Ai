# 캐릭터 바이블 — 몽글이 (Monggeul-i) [가제 — 사용자 확인 전]

## 설정
- **이름**: 몽글이 (가제, 다른 이름 원하면 교체 가능)
- **종**: 하늘에 사는 작고 동글동글한 구름양(cloud-sheep) 캐릭터
- **성격**: 호기심 많고 다정하지만 가끔 서두르다 실수함 — 매 에피소드에서
  작은 실수를 통해 나눔·배려·정리 같은 생활 습관을 배워감
- **세계관**: "몽글마을" — 구름 위에 떠 있는 작은 마을. 친구들과 매일
  소소한 모험을 겪음 (친구 캐릭터는 추후 에피소드에서 추가)
- **말투**: 짧고 쉬운 문장, 같은 구절을 반복해서 노래처럼 기억에 남게 함
  (예: "괜찮아, 괜찮아, 다시 해보면 돼!")

## 외형
- 파스텔 하늘색의 동글동글한 양털 몸(목화솜 같은 질감)
- 짧고 통통한 다리, 작고 동그란 귀
- 크고 반짝이는 눈(따뜻한 갈색), 눈에 과도한 하이라이트 없이 부드러운
  캐치라이트만
- 작은 단추 코, 다정한 미소
- 볼에 옅은 파스텔 핑크 블러셔
- 목에 민트색 니트 목도리(작은 노란 별 버튼 장식) — 몽글이의 상징 아이템
- 스타일: 3D 스타일라이즈드(픽사·드림웍스 느낌), 과장되고 사랑스러운
  비율, 무섭거나 날카로운 디테일 전혀 없음
