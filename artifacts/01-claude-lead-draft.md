# INSTAGRAM REELS 제작 패키지
**주제:** 릴스 조회수를 올리는 실전 팁 (알고리즘 신호 기반)
**포맷:** 세로 9:16 | 목표 런타임: **78초** (90초 이내)
**톤:** 캐주얼 + 실전 튜토리얼, 클릭베이트 단정 표현 금지

---

## 0. 클레임 분류표 (제작 전 필수 확인)

| 소스 내용 | 분류 | 비고 |
|---|---|---|
| 첫 3초 훅이 없으면 스크롤당한다 | **INTERPRETATION** (업계 통설) | 스크립트에 "~라고 알려져 있다"로 서술 |
| 완시청률/공유/저장/재시청이 핵심 신호 | **FORECAST/INTERPRETATION** | 정확한 가중치·공식 비공개 — 단정 금지 |
| 세로 풀프레임 + 자막이 무음 자동재생에 유리 | **FACT(플랫폼 환경)** + **INTERPRETATION(효과 해석)** | 무음 자동재생은 플랫폼 특성, 효과는 통설 |
| 트렌딩 오디오 → 탐색 탭 노출 확률 상승 | **INTERPRETATION** | 구체적 트렌딩 목록 `[VERIFY-GEMINI]` |
| 업로드 빈도/일관성이 성장에 도움 | **INTERPRETATION** | 최적 수치 단정 금지, 계정별 상이 명시 |
| 캡션 CTA → 참여율 도움 | **INTERPRETATION** | 통설, 수치 없음 |
| 해시태그 발견 신호 비중 축소 | **INTERPRETATION, 상충 가능성 있음** | 불확실성 유지, "최근 의견도 있다"로 서술 |

> 이 표는 내레이션에 "확정된 사실"처럼 들리는 문장이 없도록 체크하는 기준입니다. 아래 스크립트는 전부 이 분류를 반영해 작성했습니다.

**[0:54–1:02] 팁 6 — 캡션 CTA**

## 6. 트렌딩 오디오 가이드 (방향성만 — 실제 곡 지정 불가)

- `[VERIFY-GEMINI: 현재 Instagram 탐색 탭/릴스에서 상승 중인 트렌딩 오디오 목록 및 사용 가능 여부(지역/라이선스 포함)]`
- 선정 기준 가이드:
  - 영상 톤(차분한 튜토리얼)에 맞는 **미드 템포 비트, 과하게 튀지 않는 트렌딩 사운드** 우선
  - 업로드 시점 기준 "떠오르는 중" 단계의 오디오(이미 포화 상태인 오디오는 효과 낮을 가능성 — INTERPRETATION)
  - 보이스오버가 메인이므로, 오디오는 **배경 볼륨으로 낮게 믹스**하거나 보이스오버 구간에는 오디오 없이 훅/전환 구간에만 짧게 삽입하는 방식 고려

## 8. 온스크린 텍스트 / 자막 번인 타이밍 스펙

| 항목 | 스펙 |
|---|---|
| 폰트 크기 | 화면 높이 기준 최소 7~8% (작은 화면에서도 가독) |
| 안전 영역 | 상/하단 각 14% 여백 확보 (UI 아이콘/캡션 가림 방지) |
| 자막 등장 타이밍 | VO 시작과 **동시 또는 0.2초 이내** 싱크 |
| 자막 유지 시간 | 최소 1.5초 이상 (읽기 시간 확보), 다음 자막과 0.3초 이상 교차 없음 |
| 강조 처리 | 숫자/핵심 키워드(TIP 1~7, "첫 3초" 등) 볼드 또는 색상 강조 |
| 색상 대비 | 배경 대비 명도차 충분히 확보 (스톡 영상 밝기 변동 고려, 텍스트 박스/외곽선 처리 권장) |
| 불확실 표현 자막 | "실시간 확인 필요", "계정마다 다름" 등 — 괄호/작은 글씨로 보조 표기, 메인 톤 유지 |

## 10. QC 체크리스트 (게시 전 필수 확인)

**사실/톤 검증**
- [ ] 영상/캡션 내 "무조건", "100%", "~만 하면 터진다" 식 단정 표현 없음
- [ ] 알고리즘 관련 발언이 전부 "~라고 알려져 있다 / 통설이다" 형태로 서술됨 (단정형 아님)
- [ ] 수치(%, 배수 등) 전부 삭제되었거나 `[VERIFY-GEMINI]`로 표시됨 — 임의 수치 없음
- [ ] 특정 개인/브랜드/경쟁 계정 실명 언급 없음
- [ ] 인용부호("전문가가 말했다" 등) 사용하지 않음 — 직접 인용 없다는 소스 조건 준수

**검증 대기 항목 (게시 전 Gemini 확인 필수)**
- [ ] `[VERIFY-GEMINI: 현재 시점 기준 트렌딩 오디오 목록 및 사용 가능 여부]`
- [ ] `[VERIFY-GEMINI: 현재 시점 기준 릴스 관련 트렌딩/성과 해시태그 데이터]`
- [ ] `[VERIFY-GEMINI: 알고리즘 신호(완시청/공유/저장/재시청) 관련 최신 공식/비공식 업데이트 여부]`
- [ ] `[VERIFY-GEMINI: 해시태그 발견 신호 비중 축소 주장에 대한 최신 상충 의견/자료 확인]`

**제작 스펙**
- [ ] 전체 영상 9:16, 78초 (90초 이내) 확인
