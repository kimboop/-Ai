## 6. 트렌딩 오디오 가이드 (스타일 기준)

구체적 트랙명은 넣지 않음 — 실시간으로 바뀌기 때문. 대신 **선택 기준**:

- 업로드 당일 릴스 오디오 선택 화면에서 ↗(상승) 표시가 붙은 오디오 우선 확인
- 영상 톤(캐주얼·튜토리얼)에 맞는 중간 템포, 보이스오버를 방해하지 않는 낮은 볼륨대 오디오 선택
- 훅 구간(0:00-0:03)과 비트 강조 포인트가 맞는지 확인
- 보이스오버가 주가 되는 영상이므로, 오디오는 배경음 수준(믹스 시 VO보다 –15~–20dB 권장)

`[VERIFY-GEMINI: 업로드 시점 기준 실제 트렌딩 오디오 상위 리스트 (한국 지역) 및 라이선스 상태]`

## 7. 커버 프레임 제안

- Shot 1의 정지 프레임 사용 ("⏱ 3초의 법칙" 텍스트가 선명하게 보이는 순간)
- 대안: Shot 4의 4개 아이콘(완시청/공유/저장/재시청)이 모두 나열된 프레임 — 썸네일만 봐도 "내용 요약"이 전달됨
- 텍스트 대비: 밝은 배경 + 진한 색 폰트, 또는 다크 배경 + 흰색/포인트 컬러 폰트 (무음 상태에서 피드 스크롤 중에도 읽히게)

## 8. 온스크린 텍스트 / 번인 자막 타이밍 스펙

| 항목 | 스펙 |
|---|---|
| 세이프존 | 상/하 각 250px 여백 확보 (인스타그램 UI 버튼·캡션 영역과 겹치지 않도록) — 좌우 각 80px 여백 |
| 자막 폰트 | 굵은 산세리프 (가독성 우선), 최소 크기 화면 높이의 5% 이상 |
| 자막 대비 | 텍스트 외곽선(stroke) 또는 반투명 배경 바 적용 — 어떤 영상 배경에서도 가독 보장 |
| 등장 타이밍 | 각 핵심 문장과 동시 등장, 문장 끝나기 0.3~0.5초 전 페이드아웃 시작 |
| 핵심 키워드 강조 | 각 섹션 제목(예: "3초의 법칙", "완시청·공유·저장·재시청")은 별도 색상/크기로 강조 |
| 전체 자막 커버리지 | 보이스오버 전체 구간 100% 자막 처리 (무음 시청 대비 필수) |
| 애니메이션 | 과도한 모션 금지 — 페이드 또는 짧은 슬라이드인 (0.2초 이내) |

2. `[VERIFY-GEMINI: 업로드 시점 기준 한국 지역 실제 트렌딩 오디오 상위 리스트 및 라이선스 상태]`

5. `[VERIFY-GEMINI: 해시태그의 발견 신호 비중 감소 주장에 대한 최신 출처 — 상충되는 1차 자료 유무]`
