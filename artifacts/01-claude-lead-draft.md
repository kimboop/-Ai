## 10. QC 체크리스트 (업로드 전 최종 확인)

### 콘텐츠/사실관계
- [ ] FACT/FORECAST/INTERPRETATION 라벨이 스크립트 내부 메모(제작용)에 명확히 구분되어 있는가 (실제 영상엔 노출 안 함, 내부 문서 기준)
- [ ] "무조건", "반드시 터진다" 등 단정적 클릭베이트 문구 없는지 재확인
- [ ] 특정 브랜드/경쟁 채널/개인 실명 언급 없는지 확인
- [ ] 수치(%, 배수 등) 임의 삽입 없는지 확인 — 전부 `[VERIFY-GEMINI]`로 남아있는지 체크

### VERIFY-GEMINI 미해결 항목 (업로드 전 반드시 해결 또는 영상에서 제거)
- [ ] `[VERIFY-GEMINI: 현재 트렌딩 오디오 목록 — 한국 지역]`
- [ ] `[VERIFY-GEMINI: 해시태그 알고리즘 비중 변화 관련 최신 업계 발표]`
- [ ] (선택) `[VERIFY-GEMINI: 완시청/저장/공유 신호 관련 최근 공식 발표나 업데이트 여부 — 있다면 FORECAST→FACT 승격 검토]`

### 기술/포맷
- [ ] 세로 9:16, 1080x1920 해상도 확인
- [ ] 총 러닝타임 90초 이내 (현재 스크립트 기준 약 78초 — 편집 중 초과 여부 재확인)
- [ ] 무음 상태로 1회 재생 테스트 — 자막만으로 내용 이해 가능한지 확인
- [ ] 자막 폰트 대비/가독성 저해상도 미리보기로 확인
- [ ] 커버 프레임 썸네일 미리보기 확인

### 참여 유도 요소
- [ ] 캡션 CTA 질문형 문장 포함 확인
- [ ] 저장 유도 문구 영상 내 + 캡션 양쪽에 존재 확인
- [ ] 해시태그 세트 적용 (broad + niche 최소 혼합)
