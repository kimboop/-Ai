## 10. QC 체크리스트 (업로드 전 최종 확인)

- [ ] 런타임 90초 이내 확인 (`TARGET` 충족, 현재 스크립트 약 72초)
- [ ] 전 구간 9:16 세로 풀프레임, 세이프존 내 텍스트/피사체 배치
- [ ] 전 자막(번인) 무음 상태로도 내용 이해 가능한지 무음 재생 테스트
- [ ] `[VERIFY-GEMINI]` 마커 전부 해소되었는지 확인 (트렌딩 오디오, 해시태그 비중 관련 최신 근거)
- [ ] 스크립트 내 단정형 표현("무조건", "100%") 없는지 재검토 — 톤 가이드 위반 여부
- [ ] 알고리즘 관련 발언에 "~라고 알려져 있다/통설이다" 류 불확실성 고지 문구 유지 여부
- [ ] 실명 브랜드/경쟁 채널/개인 언급 없는지 확인
- [ ] 사용 BGM/트렌딩 오디오 라이선스(상업적 사용 가능 여부) 확인
- [ ] 캡션 내 인용부호("전문가가 말했다" 식) 사용 여부 — 금지 규칙 준수
- [ ] 커버 프레임 텍스트 가독성(모바일 작은 화면 기준) 확인
- [ ] 해시태그 세트 최종 개수(과도한 나열 지양, 8~15개 권장) 및 관련성 재확인
- [ ] CTA 문구가 영상 내 음성 + 캡션 양쪽에 모두 존재하는지 확인
