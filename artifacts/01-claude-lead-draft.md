## 6. 트렌딩 오디오 가이드

**사용 불가 (실시간 데이터 없음) → 구체적 오디오명은 삽입하지 않음.**

**선정 기준 (일반 가이드):**
1. 업로드 24–48시간 전, 인스타그램 앱 내 "Audio" 검색/탐색 탭에서 상승세(↑ 화살표) 표시된 트랙 확인
2. 오디오 사용 횟수가 최근 빠르게 증가 중인지 확인 (앱 내 "Reels using this audio" 카운트 추이)
3. 영상 톤(실전 튜토리얼, 캐주얼)과 어울리는 미드템포/보이스오버 친화적 트랙 우선
4. 저작권/라이선스 문제 없는 오디오인지 확인

`[VERIFY-GEMINI: 게시 예정 시점 기준 실시간 트렌딩 오디오 Top 3–5 리스트, 장르/BPM 포함]`

## 7. 커버 프레임 제안

**추천 프레임:** Shot 1 (0:00–0:03) 훅 장면 — 스크롤이 멈춘 순간 + 텍스트 `3초 안에 안 넘겼다면?`
- 배경: 흐릿한 피드 스크롤 캡처
- 텍스트: 굵은 산세리프, 고대비(흰 텍스트 + 검정 아웃라인 또는 반투명 블랙 박스)
- 세로 프레임 상단 1/3 지점에 배치 (프로필 썸네일에서도 텍스트 가독성 확보)

## 8. 온스크린 텍스트 / 번인 자막 타이밍 스펙

| 항목 | 스펙 |
|---|---|
| 폰트 | 굵은 산세리프 (가독성 우선, 최소 두께 Bold 이상) |
| 크기 | 화면 너비 기준 텍스트 높이 약 6–8% (세로 1920px 기준 약 90–120px) |
| 위치 | 화면 중앙~하단 1/3, 단 **하단 15%는 피하기** (댓글/좋아요/공유 아이콘 UI 겹침 방지 안전지대) |
| 동기화 | VO 발화 시작과 ±0.2초 이내 등장, 문장 단위로 끊어서 표시 (한 번에 2줄 이내) |
| 대비 | 텍스트 배경에 반투명 블랙 박스(opacity 40–60%) 또는 흰 텍스트+검정 아웃라인 |
| 전환 | 컷 전환 시 텍스트는 페이드 아님, 즉시 교체(하드컷)로 리듬감 유지 |
| 팁 번호 텍스트 | 각 Tip 등장 시 좌상단 또는 중앙 상단에 `TIP N` 배지 스타일로 0.5초 고정 후 서브텍스트와 함께 유지 |

## 9. CTA (최종 콜투액션)

**발화 (1:18–1:25):**
"오늘 알려드린 7가지, 한 번에 다 적용하지 말고 영상 하나에 2–3개씩만 테스트해보세요. 어떤 게 제일 효과 있었는지 댓글로 알려주세요. 저장은 필수!"

**액션 유도 3종:**
1. 저장 (SAVE) — 다시 보기용
2. 댓글 (COMMENT) — "어떤 팁 써봤어요?" 질문형
3. 캡션 CTA와 중복 강화 (영상 내 음성 + 캡션 텍스트 이중 노출)
