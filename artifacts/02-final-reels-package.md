## 6. 트렌딩 오디오 가이드 (구체 트랙명 없음 — 스타일 가이드만)

**구조적 가이드 [INTERPRETATION]:**
- 업로드 직전 24~48시간 내 "트렌딩" 표시가 붙은 오디오 중, 영상 내용/톤과 자연스럽게 맞는 것 선택
- 너무 포화된(이미 수십만 건 사용된) 오디오보다 "상승 초기" 단계 오디오가 탐색 노출에 유리하다는 의견 존재 — 확정 아님
- 보이스오버 중심 영상이므로, 오디오는 배경 BGM 톤으로 낮게 믹스하거나 인트로/아웃트로 구간에만 포인트로 사용 권장

**[검증 완료 — 조사 결과]:** 특정 트랙명을 이 문서에 고정해서 적는 건 애초에 불가능/부적절하다는 게 조사 결론이다. Instagram의 "트렌딩 오디오"는 앱 내에서 며칠 단위로 갱신되는 실시간 목록이라, 오늘 조사한 트랙명을 적어 넣어도 실제 업로드 시점엔 이미 바뀌어 있을 가능성이 높고, 지역(한국)별 상세 트렌딩 목록을 외부에서 정적으로 가져올 공식 API/신뢰 가능한 소스도 없다. 대신 **업로드 직전에 아래 방법으로 직접 확인**하는 게 유일하게 신뢰 가능한 방법이며, 섹션 3의 샷 #6("트렌딩 오디오 체크")이 바로 이 단계를 영상 안에 보여주는 장면이다:
1. 릴스 만들기 → 음악/오디오 아이콘 → **"트렌딩"** 탭 — 며칠 단위로 갱신되는 상위 목록 표시
2. (프로페셔널 계정 · 일부 국가 한정 기능일 수 있음) **설정 → 프로페셔널 대시보드 → 트렌딩 오디오**
3. 릴스를 스크롤하다 오디오 이름 옆에 **↑(상승) 아이콘**이 보이면 그게 현재 뜨는 오디오
4. **@creators** 공식 계정 — 트렌딩 오디오/포맷을 주기적으로 소개
- **라이선스**: 위 방법으로 고른 오디오가 Instagram 앱 내 공식 오디오 라이브러리에 있는 트랙이면 상업적 Reels 사용에 별도 허가가 필요 없다는 게 일반적 운영 방식이나, 계정 종류(개인/비즈니스)나 음원별 예외가 있을 수 있어 업로드 전 해당 트랙 상세 페이지의 사용 조건 표시를 직접 확인할 것.
