## 5. HASHTAG SET

> [FACT — 검증 완료] Instagram은 2025년 12월부터 게시물/릴스당 해시태그를 **5개로 제한**했고, "검색을 돕지만 도달을 넓히지 않는다"고 공식적으로 밝혔다 (PR #4 조사에서 확인, 출처는 아래 요약 참고). 기존 Broad 5개 + Niche 5개 = 10개 제안은 상한을 크게 초과하므로 **5개로 조정**했다.

`#릴스편집 #릴스편집팁 #숏폼편집 #영상편집꿀팁 #완시청률`

> [검증 완료] 해시태그별 "실제 검색량" 같은 세부 수치는 Meta가 공개하지 않아 어차피 외부에서 검증 불가능한 항목이었음 — 위 FACT에 따라 해시태그는 애초에 "검색 분류용"으로만 취급하고 노출량 기대 자체를 하지 않는 게 맞는 접근.

**Branded:** 소스 자료에 계정 고유 브랜드명이 제공되지 않았으므로 **생략 확정** (임의 생성 안 함).

## 6. TRENDING AUDIO 가이드

- **구조적 요구사항:** 비트가 명확히 구분되는 음악(4샷 이상 컷 포인트와 정렬 가능해야 함), BPM 90~120대 권장 (TARGET — 임의 설정, 검증된 "최적 BPM" 아님)
- **톤:** 미니멀/로파이 계열, 보이스오버를 가리지 않는 낮은 음량대
- **[검증 완료 — 조사 결과]:** 특정 트랙명을 문서에 고정하는 건 애초에 불가능하다는 게 조사 결론이다 (며칠 단위로 바뀌는 실시간 목록 + 카테고리별 정적 소스 없음, PR #4에서 동일하게 확인됨). 업로드 직전 아래로 직접 확인:
  1. 릴스 만들기 → 오디오 아이콘 → **"트렌딩"** 탭
  2. (프로페셔널 계정 일부 국가 한정) 설정 → 프로페셔널 대시보드 → 트렌딩 오디오
  3. 스크롤 중 오디오명 옆 **↑ 아이콘**
  4. **@creators** 공식 계정
- 대안: 트렌드 오디오 확인 전까지는 **오리지널 사운드(내레이션+로열티프리 BGM)**로 우선 발행 권장 — 이 영상은 보이스오버 중심이라 오히려 원 사운드가 자연스러움
